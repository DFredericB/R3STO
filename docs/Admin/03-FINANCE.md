# Finance & Compta - /finance
Fichier : src/views/Admin/Finance.tsx
Store : AUCUN (local state demo)

## Elements
- 5 onglets : Overview / Factures / Frais / TVA / Tresorerie
- Overview : revenue total, depenses, benefice net
- Factures : liste (id, client, date, montant, echeance, statut)
- Frais : par categorie (loyer, salaires, fournisseurs, marketing, IT)
- TVA : taux suisses (8.1% / 2.6% / 3.8%), calculateur mensuel
- Tresorerie : graphique cash flow

R3STO — App design system · Light + Dark mode

Système unifié pour app.r3sto.ch · primary bleu duo · accent cuivre · sémantique success/warn/error/info · neutres light/dark

Un seul système, deux thèmes. Light par défaut (jour, lumière du resto). Dark pour le service du soir (écrans en faible lumière, moins fatigant pour le staff). Le bleu R3STO #1d4f91 reste signature, le bleu clair #3b82f6 devient l'accent vif en dark mode. Le cuivre #b8632b apporte la chaleur gourmand. Les couleurs sémantiques (vert/ambre/rouge/bleu) restent constantes pour la cohérence des alertes.

Light mode : couleurs vives sur fond clair, idéal pour utilisation tablette en journée, vue rapide sur transats/comptoir.
Dark mode : surfaces très foncées, texte beige clair, accent bleu clair plus visible — réduit la fatigue oculaire pendant le service du soir.

Toggle automatique possible : déclenchement par horaire (ex: dark après 18h) OU par luminosité ambiante (capteur tablette) OU manuel utilisateur.

Couleurs sémantiques constantes entre les 2 modes : vert success, ambre warning, rouge error, bleu info. Les niveaux de saturation sont légèrement ajustés pour la lisibilité.

Le système s'applique aussi à : admin.r3sto.ch, bill.r3sto.ch, demo.r3sto.ch (mêmes tokens, même structure).

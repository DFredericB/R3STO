Analyse — quel mode par défaut ?

☀ Light mode

Pour : plus accueillant pour la prise en main, lisible en plein jour, ambiance "comptoir éclairé".

Contre : moins reposant l'œil pour les services du soir (faible luminosité ambiante), moins "premium tech".

🌙 Dark mode

Pour : déjà déployé et beau, idéal en service du soir (écran tablette en faible luminosité ambiante), vibe "outil pro premium", cohérent avec auth.r3sto.ch.

Contre : moins immédiatement accueillant pour un nouveau restaurateur qui découvre l'outil.

Ma recommandation : Dark par défaut (cohérent avec auth/light actuel, déjà déployé, ce qui vous a plu), avec un toggle ☀/🌙 dans Réglages pour ceux qui préfèrent le clair. Auto-switch optionnel par horaire (clair le jour, sombre après 18h). Les deux modes utilisent les mêmes tokens R3STO, juste avec [data-theme="light"] qui override les CSS variables.

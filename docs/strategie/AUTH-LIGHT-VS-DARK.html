Analyse · quelle palette dégage le plus l'ADN R3STO ?

🌙 Dark · défaut

Vibe : premium, sérieux, gastronomique. Une nuit étoilée dans un bel établissement.

Pour : Lightspeed, Square POS, Toast — toutes les caisses pros restaurant sont dark. R3STO s'aligne avec les outils du métier. L'or sobre #a07e2a brille vraiment sur navy nuit, là où il devient terne sur blanc.

Différenciation : 95% des SaaS B2B sont blancs (Stripe, Notion, Linear). R3STO dark = signature mémorable, sentiment "luxe protégé".

☀ Light · toggle utilisateur

Vibe : épuré, propre, professionnel suisse. Confort en plein jour.

Pour : restaurateur âgé, comptoir en plein soleil, prise de réservation rapide entre 11h et 14h. Lisibilité maximale sans fatigue oculaire.

Cohérent avec dark : exactement les mêmes tokens primary #1c2e58 et gold #a07e2a — c'est la MÊME palette, juste retournée.

Verdict : dark par défaut, light en toggle. Tous les sites B2B R3STO (/pro, /mini, auth, app, admin, bill, booking, menu, delivery, demo) déployés en dark par défaut. Le restaurateur active le light via un toggle dans son compte si besoin. Le bundle CSS porte les deux thèmes en [data-theme="light"] override. r3sto.com B2C annuaire garde sa palette distincte crème/cuivre.

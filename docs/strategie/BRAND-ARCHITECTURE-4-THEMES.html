4 thèmes, 1 famille parfaitement cohérente

Famille de marques R3STO : 3 sub-brands B2B dark (Pro · Carat luxe · Pass consumer) avec logo doré + 1 light theme partagé entre l'app toggle ET l'annuaire r3sto.com B2C, avec logo navy bleu nuit. Tous reliés par l'or sobre `#a07e2a` — le fil rouge qui dit "même famille". Le navy bleu nuit `#1c2e58` est réservé au mode light, où il pop sur fond blanc.

L'or `#a07e2a` = signature commune sur 4 thèmes

Ce ton chaud sobre (presque mat, jamais clinquant) signe les CTAs et accents sur les 4 thèmes. Sur les 3 fonds dark (Pro, Carat, Pass), l'or porte aussi le logo. Sur le thème light (annuaire + app toggle), le navy bleu nuit #1c2e58 reprend la main pour le logo car il pop sur fond clair. Le navy n'apparaît plus du tout sur fond sombre.

Quel thème pour quel site ?

Mapping site → thème, validé. Les sites B2B partagent le thème R3STO Pro core. Les sub-brands Carat et Pass héritent de la palette mais inversent le fond. L'annuaire B2C est distinct.

🌙 R3STO Pro (core dark)

Fond navy nuit + logo doré (pas navy, comme Carat/Pass).

Sites : /pro · /mini · auth · app · admin · bill · booking · menu · delivery · demo

+ toggle vers R3STO Light pour app uniquement

◼ R3STO Carat (luxe)

Noir profond + or chaud. Réservé aux établissements 3 étoiles / palaces.

Sites : carat.r3sto.ch (futur) · onboarding sur invitation

programme premium pour membres haut de gamme

🌲 R3STO Pass (consumer)

Vert forêt + or. Abonnement consumer (gourmets qui réservent souvent).

Sites : pass.r3sto.ch (futur) · app mobile consumer

programme abonnement payant pour utilisateurs finaux

☀ R3STO Light (toggle + B2C)

Fond clair + logo navy bleu nuit + or signature. Seul thème où le navy `#1c2e58` apparaît visible.

Sites : r3sto.com racine · /restaurants · fiches resto publiques · app toggle utilisateur

cohérence app⇄annuaire — la version light de l'app = l'annuaire B2C

Le fil rouge · l'or sobre

L'or `#a07e2a` est présent sur les 4 thèmes aux endroits où l'utilisateur prend une action ou voit une distinction premium. C'est ce qui assure que tous ces sites disent "je suis R3STO" malgré leurs fonds différents.

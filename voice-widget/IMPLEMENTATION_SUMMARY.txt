INTEGRATION EXAMPLES
================================================================================

OPTION 1 - Standalone (Demo):
Simply open index.html in a browser.

OPTION 2 - Embed on Website:
<script src="https://widget.r3sto.com/voice/embed.js" data-resto="legourmet"></script>

OPTION 3 - Programmatic:
<script src="https://widget.r3sto.com/voice/embed.js" data-resto="legourmet"></script>
<script>
    R3STO_VOICE.open();  // Open widget
    R3STO_VOICE.setCallback((res) => console.log(res));
    document.addEventListener('r3sto-reservation-confirmed', (e) => {
        // Send to backend API
        fetch('/api/reservations', { method: 'POST', body: JSON.stringify(e.detail.reservation) });
    });
</script>

================================================================================
NATURAL LANGUAGE PARSING
================================================================================

DATES:
- "aujourd'hui" → today's date
- "demain" → tomorrow
- Day names: "lundi", "mardi", etc.
- Relative: "ce soir", "ce midi"
- Explicit: "15/03", "15-03-2026"
- Format: Returns ISO 8601 (YYYY-MM-DD)

TIMES:
- 24-hour format: "19h", "19h30", "19:30"
- 12-hour: "sept heures du soir", "une heure"
- Keywords: "midi", "matin", "soir"
- Format: Returns HHh00 (e.g., "20h00")

GUEST COUNTS:
- Words: "un", "deux", "trois", "quatre", "cinq", "six", "sept", "huit", "neuf", "dix", "onze", "douze", "treize", "quatorze", "quinze", "seize", "dix-sept", "dix-huit", "dix-neuf", "vingt"
- Phrases: "2 personnes", "pour 4", "six"
- Range: 1-20 guests

NAMES:
- Uses last word from user's speech
- Capitalizes properly: "Dupont", "Martin"
